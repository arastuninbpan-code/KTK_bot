# Техническая памятка (для владельца)

## Из чего состоит система
| Часть | Где живёт | Что делает |
|---|---|---|
| Google Таблица | Google Drive | База данных. Листы «Сотрудники», «Расписание», «Площадки» и скрытые служебные |
| Apps Script | привязан к таблице | Вся логика, боты, уведомления, API |
| Cloudflare Worker `solitary-fire-f032` | Cloudflare | Принимает вебхуки Telegram/VK и запросы `/api`, пересылает в Apps Script |
| Сайт (папка `docs/`) | Cloudflare Workers (`ktk-bot`), запасной вариант — GitHub Pages | Приложение |
| Репозиторий GitHub | github.com | Исходники. После изменений в `main` Apps Script обновляется автоматически (GitHub Actions + clasp) |

## Адреса
- Приложение: `https://app.kstoshasmena.ru`
- Временный адрес: `https://ktk-bot.a-rastuninbpan.workers.dev`
- Свойство Apps Script `APP_URL` — адрес, который боты показывают на кнопке «Открыть приложение».

## Свойства скрипта (Project Settings → Script Properties)
`SHEET_ID`, `TELEGRAM_BOT_TOKEN`, `RELAY_URL`, `APP_URL`, токены VK. Значения нигде не публикуйте.

## Резервные копии
1. Раз в месяц: в таблице «Файл → Создать копию».
2. Историю версий смотрите в «Файл → История версий».
3. Код хранится в GitHub.

## Что делать при поломке
1. Сайт не открывается: откройте временный адрес. Если он работает, проблема в домене (Cloudflare → DNS).
2. Боты молчат: проверьте Worker в Cloudflare и вебхук бота.
3. Нет обновлений в таблице: Apps Script → «Триггеры», должны быть активны.
4. Сообщите разработчику (мне) текст ошибки и время.

## Смена домена и вход
Токен входа привязан к адресу сайта. После переезда на новый адрес сотрудникам нужно войти один раз заново.

## Прогрев (чтобы бот отвечал быстро)
Скрипт Google «засыпает», и первое сообщение после паузы ждёт 5–12 секунд. Чтобы не засыпал, посредник раз в минуту стучится в него:
1. Cloudflare → Workers & Pages → `solitary-fire-f032` → Edit code: вставьте актуальный код из `relay/worker.js` репозитория и нажмите Deploy.
2. Settings → Triggers → Cron Triggers → Add → выражение `* * * * *` (каждую минуту) → Save.
Нагрузка ничтожная (1440 запросов в сутки при бесплатном лимите 100 000).

## Кнопки «Увидел(а)» / «Не могу»
- **Telegram:** после обновления скрипт сам один раз заново настраивает вебхук (в `_лог` появится «вебхук обновлён»). Вручную: в Apps Script запустить `setWebhook`.
- **ВКонтакте:** в группе → Управление → Настройки → Работа с API → Callback API → вкладка «Типы событий» → включить **«Действия с кнопками»** (`message_event`). Без этого кнопки в ВК нажимаются, но ответ не доходит.
- Отметки: скрытый лист `_подтверждения` (ID события, телефон, статус ok/no, время, имя).

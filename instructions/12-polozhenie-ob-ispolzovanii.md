# Правила пользования приложением (для сотрудников)

**Черновик для внутреннего приказа или ознакомления.**

1. Приложение — рабочий инструмент. Расписание и данные коллег нельзя пересылать посторонним.
2. Код входа нельзя передавать другим. Вход по чужому номеру запрещён.
3. В обсуждениях пишем только по работе. Фото только рабочие, без посторонних лиц, документов и личных данных.
4. Свои «не могу работать» указывать заранее и честно.
5. Сменили номер, должность или ушли — сообщите администратору.
6. Администратор вправе закрыть доступ при нарушении правил или увольнении.
7. С правилами ознакомлен(а): ______________ (подпись), дата ______.

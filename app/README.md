# Сайт, вход по коду и бот на Netlify

Один проект на Netlify (бесплатно): сайт для сотрудников и директора, вход по коду из бота, API, бот Telegram и напоминания.
Данные по-прежнему лежат в вашей Google Таблице: её можно править руками, через сайт и (позже) через бота.

## Как это работает
- **Вход.** В боте `/login` → код из 6 цифр (10 минут, один раз) → ввод на сайте. Бот уже знает номер человека, поэтому пароли не нужны.
- **Роли.** В листе «Сотрудники» третья колонка «Роль». Слово «директор» даёт право менять расписание, остальные только смотрят.
- **Расписание** правится в том же виде, как ведёт театр (строка на событие: дата/время, спектакль (зал), роли с фамилиями).
  Сайт при сохранении сам записывает строку в таблицу и вставляет её по порядку дат.
- **Уведомления.** Раз в минуту проход сравнивает таблицу с прошлой версией; после правки директора на сайте проход идёт сразу.
  Приходят: назначили, сняли, перенесли (было → стало), за сутки и за час до смены.

## Запуск на Netlify
1. Netlify → **Add new site → Import an existing project** → GitHub → репозиторий `KTK_bot`.
2. Настройки сборки: **Base directory** = `app` (остальное подхватится из `app/netlify.toml`). Deploy.
3. **Site configuration → Environment variables** (значения только здесь, не в коде):

| Переменная | Значение |
|---|---|
| `SHEET_ID` | ID таблицы (из ссылки) |
| `GOOGLE_CREDENTIALS_JSON` | всё содержимое JSON-ключа сервисного аккаунта (доступ «Редактор» к таблице) |
| `TELEGRAM_BOT_TOKEN` | токен бота |
| `SESSION_SECRET` | любая длинная случайная строка (подпись входа) |
| `SETUP_KEY` | любое слово-пароль для разового подключения бота |

4. После деплоя откройте один раз `https://ВАШ-САЙТ.netlify.app/api/setup?key=ВАШ_SETUP_KEY`: бот подключится к сайту.
5. В листе «Сотрудники» добавьте колонку C «Роль» и впишите «директор» у нужного человека.
6. Напишите боту `/login` и войдите на сайте.

Обновления: `git push` в `main` — Netlify публикует сам (как в DNA).

## Разработка
```
cd app
npm test                 # тесты логики, бота и API (node --test)
node dev/server.mjs      # стенд с тестовыми данными: http://localhost:8788
```

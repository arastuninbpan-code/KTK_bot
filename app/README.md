# Сайт, вход по коду и бот (GitHub Pages + Apps Script)

Бесплатно и без своего сервера. Данные лежат в Google Таблице.

- **Сайт** — папка `docs/`, публикуется на GitHub Pages.
- **Бот и API** — `apps_script_bot/Code.gs` (генерируется: `node app/build-gas.mjs`), работает в Google Apps Script.
- **Relay** — `relay/worker.js` на Cloudflare Workers (Telegram требует ответ 200, Apps Script отвечает 302).

## Как устроена таблица
- **Расписание:** `Дата | Начало | Конец | Событие | Площадка | роли…` (по строке на событие; два показа в день — две строки). Старый вид театра (время в ячейке даты, зал в скобках) читается тоже, а `styleSheets` переносит его в новый вид, сохранив копию листа.
- **Площадки:** лист «Площадки» (название, заметка). Список в колонке «Площадка» выпадающий; новые площадки можно добавлять и на сайте. Занятость видно на вкладке «Площадки» сайта; при создании события на занятой площадке сайт предупреждает.
- **Сотрудники:** `ФИО | Телефон | Роль | Логин | группы…`. Любая колонка правее «Логина» с названием в шапке — группа, в ячейках галочки. В сайте группа добавляет всех своих сразу.

## Синхронизация
- Правка таблицы руками: после ~5 секунд тишины приходят уведомления, а сайт подхватывает изменения за ~8 секунд (раз в 8 секунд он спрашивает «версия данных изменилась?», таблицу при этом сервер не читает).
- Правка на сайте: уведомления уходят сразу.

## Запуск
1. Apps Script: вставьте новый `Code.gs`, свойства скрипта: `SHEET_ID`, `TELEGRAM_BOT_TOKEN`, `RELAY_URL`, `APP_URL`.
2. Запустите `setup`, затем **Развернуть → Управление → ✏️ → Новая версия**, потом `setWebhook` и `styleSheets` (перенос расписания, площадки, группы, оформление).
3. GitHub Pages: Settings → Pages → `main`, папка `/docs`.
4. Cloudflare-воркер из `relay/worker.js`: сайт ходит в API через него (`/api`), Telegram — через секретный адрес.
5. Бот: `/login` присылает логин, он же подключает бота. Демо без сервера: `?demo` (логины `ADMIN`, `READER`).

## ВКонтакте и публикация афиши
- Бот работает и в личных сообщениях сообщества ВК (сотрудник пишет сообществу номер или логин, дальше всё как в Telegram).
- Свойства скрипта: `VK_TOKEN` (ключ доступа сообщества), `VK_GROUP_ID` (число из адреса сообщества), `VK_SECRET` (секретный ключ Callback API), `VK_CONFIRM` (строка подтверждения; её же задаёте в переменных воркера).
- Callback API: адрес `https://<воркер>/vk/<PATH_SECRET>`, событие «Входящее сообщение».
- Афиша: админ или редактор пишет боту `/post` (предпросмотр без имён сотрудников), затем `/post да`: публикация на стене группы ВК (`VK_TOKEN` + `VK_GROUP_ID`) и/или в Telegram-канале (`TG_CHANNEL`, бот — админ канала).

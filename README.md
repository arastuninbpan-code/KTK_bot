# Расписание театра: Google Таблица → уведомления в Telegram (и MAX)

Администратор ведёт расписание в Google Таблице, как и раньше. Сотрудники подключаются к боту и получают сообщения,
когда что-то меняется в их сменах. Приложения и сайта нет. Через бота ничего менять нельзя: он только присылает уведомления
и показывает расписание.

## Что умеет бот
- Уведомления: 🆕 вас назначили · ❌ сняли · ✏️ перенесли время/зал · 📅 напоминание **за сутки** · ⏰ **за час** до смены.
  Время берётся из первой колонки (при нескольких, например «11.00 и 13.00», — самое раннее). Если времени нет,
  напоминание одно: накануне в 18:00. Каждое приходит один раз.
- Команды: `/shifts` — мои смены, `/schedule` — афиша с составом, `/stop` — отключить.
- Подключение: `/start` → «Поделиться номером» (или номер текстом в любом формате: `8…`, `+7…`, со скобками и без).
  Номер должен быть в листе «Сотрудники».

## Как устроено
Бот целиком живёт в **Google Apps Script** (`apps_script_bot/Code.gs`): бесплатно, без сервера и банковской карты.
Telegram присылает сообщения сразу (вебхук), ответ приходит за секунды. Правки таблицы подхватываются примерно за минуту.
Состояние бот хранит в служебных листах той же таблицы («Подписчики» читаемо, «_служебное» — технический, их не править).

## Таблица
Лист **«Расписание»** — как его ведёт театр:

| Дата/Время | Спектакль/Сцена | Администратор/Капельдинер | Гардероб/Уборщица | Касса | Монтировка | Актеры, свет, звук |
|---|---|---|---|---|---|---|
| 04.10 11.00 и 13.00 | Спектакль «Бука» (малая сцена) | Иванова М.В. | Морозова Н.М. | Орлова А.В. | | |

- Роль берётся из заголовка колонки, зал — из скобок «(малая сцена)», время — из первой колонки.
- Несколько людей в ячейке: `Иванова А.А./ Петрова Б.Б.` или через пробел — разберётся. Диапазон `25.10 до 31.10` разворачивается по дням.
- В строке два события — они считаются одним, с общим составом. Пустые дни пропускаются.
- Имена можно писать по-разному: «Дьячков», «Дьячков Н.А.», «дьячков н. а» — бот узнает человека по фамилии и инициалам.
  Если в списке два однофамильца, а в расписании только фамилия, бот никому не напишет (укажите инициалы).
- Колонку «Дата/Время» лучше сделать «Обычным текстом» (Формат → Числа), чтобы Google не превращал `04.10` в дату.

Лист **«Сотрудники»**: колонка A — ФИО, B — телефон (в любом формате, можно несколько через запятую). Кого нет в списке,
не подключится; убрали из списка — уведомления прекращаются.

## Установка (один раз, ~10 минут)
1. **Apps Script.** Откройте https://script.google.com/home/start → «Новый проект» (тем аккаунтом, которому принадлежит таблица).
   Удалите код, вставьте содержимое [`apps_script_bot/Code.gs`](apps_script_bot/Code.gs), сохраните.
2. **Свойства.** «Настройки проекта» (шестерёнка) → «Свойства скрипта»: `SHEET_ID` (ID таблицы из ссылки) и `TELEGRAM_BOT_TOKEN`.
3. **Запустите `setup`** (выбрать функцию в списке → «Выполнить»), разрешите доступ («Дополнительные настройки → Перейти … → Разрешить»).
4. **Веб-приложение.** «Начать развертывание» → «Новое развертывание» → тип «Веб-приложение» → «Выполнять от имени: Я»,
   «У кого есть доступ: Все» → «Развернуть». (При любом изменении кода нужно «Управление развертываниями» → карандаш → «Новая версия».)
5. **Свойство `WEBAPP_URL`** = адрес веб-приложения из окна «Развертывание» (оканчивается на `/exec`). **Запустите `setWebhook`.** В журнале будет `{"ok":true,…}`. Проверка: функция `webhookInfo` — в `last_error` не должно быть ошибок.
6. Напишите боту `/start`.

Токен MAX появится позже: добавится тем же способом (свойство `MAX_BOT_TOKEN`).

## Тесты
`node --test apps_script_bot/test.js` (гоняет тот же `Code.gs` без Google).

## Запасной вариант: Python
В корне лежит прежняя версия на Python (`main.py`; GitHub Actions `bot.yml` запускается вручную, либо `python main.py` на сервере).
Тесты: `pip install -r requirements-dev.txt && python -m pytest`. Одновременно с вебхуком её запускать нельзя.
